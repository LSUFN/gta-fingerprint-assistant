# GTA 在线模式 - 名钻赌场 / 佩里科岛指纹辅助 HUD (C# 原生版)

## 📌 工具简介
基于 **C# (.NET 原生 Windows Forms + 屏幕识别 + 扫描码输入)** 编写的 GTA 5 名钻赌场与佩里科岛指纹助手。

## 游客与账号模式

正式助手提供两种清晰状态：游客模式可以完整识别并显示答案，但绝不会向游戏发送按键；登录本站账号后解锁自动操作与极速模式，无需输入激活码。客户端只生成并保存一个随机 UUID，不读取网卡 MAC、硬盘序列号或 Rockstar 账号信息。登录凭据采用 RSA-SHA256 签名并支持 7 天离线使用；每次启动会在线核验停用状态，服务器不可达时才使用有效离线凭据。本地佩里科测试场只向测试器窗口发送按键。

- **无需 Python / 额外环境**：编译为原生单文件“名钻指纹助手.exe”，直接双击运行；
- **快速本地识别**：赌场切片模板常驻内存；佩里科首次自动寻找 HUD 安全区，后续复用定位结果；
- **极简 HUD**：默认突出显示实时 2×4 动态选格，并提供可点击的 `F8 自动` 开关和 `F10 稳定/极速` 模式按钮；需要排查时可展开“诊断”查看基准切片和按键路线；
- **名钻赌场闭环执行**：执行前再次复核指纹和四个选格，从实时光标计算最短 WASD 路径，回车选格后仅在赌场模式发送 Tab；
- **置顶不抢焦点**：启用 WS_EX_NOACTIVATE，悬浮窗置顶且绝不抢占 GTA 5 键盘焦点；
- **纯视觉识别**：不读取或修改游戏内存；输入自动化仍需由使用者自行评估账号与条款风险。
- **佩里科岛模式**：自动判断八行当前片段，HUD 显示每行最短左右路线；执行前、第 4 行和第 8 行做闭环复核，八行对齐后等待游戏自动通过，不发送回车或 Tab。
- **四种手动识别模式**：在“⋯ → 识别模式”中选择名钻赌场指纹、佩里科岛指纹、佩里科岛信号箱或名钻赌场点阵键盘；助手只运行玩家选择的识别器，不自动切换，避免跨模式误判。
- **佩里科岛信号箱**：直接从真实 VOLTlab 画面读取目标电压、三组数字和 `×1/×2/×10`，只有七段数字全部有效且至少存在一组数学正确的线路时才显示或执行。
- **名钻赌场点阵键盘**：必须在青色图案闪烁阶段捕获六列位置；图案消失后保留答案，确认进入输入阶段才允许执行，超过 15 秒自动作废。
- **多分辨率**：佩里科识别会尝试多组 16:9、16:10 与 HUD 安全区布局；公开截图只能用于离线初测，仍需用无压缩实机截图回归。

## ⌨️ 快捷键列表
- **F8**：登录后开启 / 关闭全自动秒解（每次启动默认关闭）
- **F10**：登录后切换稳定 / 极速按键模式（默认稳定；极速模式面向 60FPS 以上环境）
- 全局快捷键仅保留 **F8** 和 **F10**；诊断面板中的指纹参考使用鼠标点击查看
- **破解类型**：通过“⋯ → 识别模式”手动选择；选择结果保存在本机，下次启动继续使用
- **诊断**：点击标题栏“诊断”展开/收起切片、指纹特征与按键路线
- **WEB**：打开本站工具下载与更新页面
- **窗口拖动**：按住顶部标题栏任意拖动，右侧 × 退出

## 🚀 启动方式
双击 `Start-Fingerprint-Assistant.bat` 即可启动。选择“游客使用”可直接查看识别提示；选择“登录网站账号”并在浏览器确认后可使用自动功能。如果 GTA 5 以管理员身份运行，本助手也需以管理员身份运行。

工具主页：https://gta.lsf-168.top/downloads/fingerprint-assistant

稳定模式使用更宽松的按键间隔；极速模式针对 60FPS 及以上环境缩短按键按住和界面等待时间。两种模式都只使用一条按键注入通道，不会重复发键；建议先保持稳定模式，确认连续成功后再按 F10 测试极速模式。

## 佩里科岛识别说明

真实游戏模式不会拿测试场素材参与识别。运行时把当前 GTA 画面右侧完整指纹切成八段，再与左侧八行逐行匹配并计算最短方向；测试包中的截图素材只用于本地测试场。佩里科界面匹配不到、结果不稳定、光标无法定位、GTA 5 不在前台或逐行复检失败时不会继续发送按键。

坐标与算法思路参考 [infpdev/gtao-heist-toolkit](https://github.com/infpdev/gtao-heist-toolkit) 的 `Rubio.py` / `ElRubio.ahk`，已按其许可要求保留署名；本项目为独立 C# 实现。

## 佩里科本地闭环测试场

双击 `Start-Cayo-Test-Lab.bat` 或 `CayoFingerprintSimulator.exe` 会启动全屏测试器，模拟器会自动拉起独立的测试模式助手。当前只发布一套来源可追溯的真实游戏指纹；每轮仍会独立随机八行切片和起始光标。测试助手先从屏幕画面识别八行答案，再用本地状态桥复核每次按键后的光标和完成状态，因此可以同时验证视觉识别、解题和按键闭环。测试模式只向测试器发送按键，不进入赌场识别链路；正常游戏模式仍保持每次启动默认关闭。
- **按键 R / 空格**：重新随机打乱当前门禁切片；
- **按键 F5**：重新随机打乱真实指纹；
- **按键 C**：开启/关闭 4 连随机挑战（同一套真实指纹连续生成四种独立排列并累计总耗时）；
- **Tab / 回车**：人工校验比对；**Esc**：退出测试场。

测试模式通过临时状态文件与光学扫描双向验证完整按键闭环，只在显式传入 `--simulator` 时启用；普通启动仍要求前台进程是 GTA 5。素材出处记录在 `CAYO-ASSET-SOURCES.md`。

外部屏幕识别和输入自动化不等于 Rockstar 官方认可或“绝对安全”，使用前请自行了解 Rockstar 服务条款。自动功能每次启动默认关闭。

## 新破解模式的实机校准状态

信号箱与点阵键盘已经接入真实 GTA 前台截图链路，不依赖网页模拟器。离线测试会验证数字、倍率、唯一线路和六列点阵提取；正式发布前仍必须使用无压缩实机截图与完整录屏覆盖 1920×1080、不同画面质量和 Legacy/Enhanced 版本。没有通过实机样本的分辨率不会标记为已验证支持。

## Microsoft Store 构建

商店版使用 MSIX，由 Microsoft Store 签名并负责更新；编译时定义 `MICROSOFT_STORE`，因此不会启动官网 EXE 更新器。官网 Inno Setup 版仍保留原有自动更新。完整构建和 Partner Center 身份参数说明见 `docs/MICROSOFT-STORE-MSIX.md`。
